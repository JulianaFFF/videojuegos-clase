# Ejercicio 4 - S4
Titulo y textos con fuente TTF, pausa con P, sonidos, patrón Service Locator para todos los recursos (configs, imágenes, sonidos y fuentes) y un escudo especial con recarga.

- Ejecutar: `python main.py` desde esta carpeta (o F5 en VS Code).
- Configuración activa: `assets/cfg/` (window, enemies, level_01, player, bullet, explosion, interface, shield).
- Servicios: `src/engine/service_locator.py` y `src/engine/services/`.
- Enlace de itch.io: ver `README.txt`.
